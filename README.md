# Ars Sable
Ars Sable is an integration mod that adds Sable compatibility to various mechanics in Ars Nouveau. This includes support for:
* Creating persisted position tracking for things like Warp Portals, scrolls, lectern connections, planariums, etc. 
* Fixing entity pathing and behaviors involving blocks on sublevels.
* Fixes nearby effect targetting from Rituals
* Adds support for Source and relays on sublevels
